## About This Project

This repository contains all of my lab work for Data Structures and Algorithms.  
Each chapter focuses on a different concept and includes both code and a short report explaining how it works.

I tried to keep everything simple and easy to understand, not just working code but also clear explanations.

---

## How It’s Organized

Each chapter has the same structure:

- `main.py` → the actual code  
- `CHXX_LAB_REPORT.md` → explanation of the algorithm  

Example:
CH04/
main.py
CH04_LAB_REPORT.md
